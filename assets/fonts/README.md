# Font source and usage note

`AaMeiYuJianCha-web.woff2` is the web-compatible version of **Aa梅雨煎茶** (`AaMeiYuJianCha-2.ttf`) by Aa字库.

- Source: <https://www.fonts.net.cn/font-40657159179.html>
- Retrieved: 2026-07-22
- Source-file MD5: `9933d56b64bb3c182377d0a950e6a357`
- The source page labels the font as free for non-commercial use. Commercial use requires written authorization from the rights holder.
- The downloaded archive did not include a separate license file. Confirm the applicable authorization before using this site or font commercially.

The source font contained an invalid glyph bounding box that Chrome rejected as a web font. The WOFF2 file preserves all 8,183 glyphs and only recalculates glyph bounding boxes for browser compatibility.
